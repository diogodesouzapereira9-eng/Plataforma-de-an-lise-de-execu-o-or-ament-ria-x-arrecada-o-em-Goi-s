# Plataforma-de-an-lise-de-execu-o-or-ament-ria-x-arrecada-o-em-Goi-s
É uma plataforma de análise de quanto o governo de Goiás arrecadou e gastou  no período de janeiro 2021 a dezembro de 2025, com gráficos interativos para análise do Painel e Índice de Execução Orçamentária, com a média anual e mensal de gastos e muitas outras informações.
